# NutriVida (frontend React + Vite)

La documentación del proyecto está en el [README principal](../README.md): funcionalidades, conexión con el backend, cómo ejecutarlo y pruebas.

Comandos rápidos desde esta carpeta:

```bash
npm install
npm run dev       # servidor de desarrollo (http://localhost:5173/NutriVidaProyecto/)
npm run test:run  # pruebas
npm run build     # build de producción
```
